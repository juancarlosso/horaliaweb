# HRNexus | Bootstrap 5 HR & Admin Dashboard HTML Template

HRNexus is a modern, professional Bootstrap 5 admin dashboard template designed for HR platforms, employee management systems, recruitment portals, payroll applications, internal business tools and enterprise dashboards.

The package includes **89 ready-to-use HTML pages** with a consistent design system, responsive layouts, dark mode support and multiple visual/layout variations.

## Responsive

The template is designed mobile-first with dedicated responsive behavior for desktop, tablet and mobile breakpoints.

## Customization

The source SCSS is organized into abstracts, base styles, layout, components, theme presets and page-specific styles. Production files are supplied in `dist/`, while editable source files are supplied in `src/`.

## Documentation

Begin with `documentation/README.md` for installation, structure, customization and asset information.

## Fonts & Preview Assets

DM Sans is loaded from Google Fonts. Bootstrap Icons are loaded from jsDelivr. No stock photographs are required for the core template pages.

## Important

This is an HTML admin dashboard template. It is a front-end UI kit and does not include a backend, database, authentication server, payment gateway or production HR business logic.
