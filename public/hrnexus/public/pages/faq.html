Frequently Asked Questions

Find answers to the most common questions about HRNexus features, billing, and integrations.

How do I add a new employee to the system?
Getting Started
Navigate to Employees → Click "Add Employee" in the top right. Fill in the required fields: name, email, job title, department, and start date. An activation email will be sent automatically. The new profile will be visible immediately in your employee directory.
What browsers does HRNexus support?
Getting Started
HRNexus supports all modern browsers including Chrome (v90+), Firefox (v88+), Safari (v14+), and Edge (v90+). We recommend Chrome for the best experience. Internet Explorer is not supported.
How is payroll calculated for part-time employees?
Payroll
Payroll for part-time employees is calculated based on their hourly rate multiplied by actual logged hours. You can set hourly rates in the employee profile under the Compensation tab. Overtime rules are configurable per region in Settings → Payroll → Rules.
Can I process payroll in multiple currencies?
Payroll
Yes! HRNexus supports multi-currency payroll. Enable it in Settings → Payroll → Multi-currency. You can assign a currency per employee, and all reports will show both local and base currency amounts.
How do leave balances carry over to the next year?
Leave
Leave carryover rules are fully configurable. Go to Settings → Leave → Carryover Rules. You can set maximum carryover days per leave type, an expiry date for carried-over days, and whether managers can override the rules for individual employees.
Can employees apply for leave from the mobile app?
Leave
Yes. The HRNexus mobile app (iOS and Android) includes full leave management. Employees can check balances, apply for leave, and track approval status. Managers receive push notifications for pending approvals.
How is employee data secured and encrypted?
Security
All data is encrypted at rest using AES-256 and in transit via TLS 1.3. We are SOC 2 Type II certified and GDPR compliant. Data is hosted on ISO 27001-certified servers with daily automated backups retained for 90 days.
Can I restrict which IP addresses can access HRNexus?
Security
Yes, IP allowlisting is available on Business and Enterprise plans. Configure it in Settings → Security → Access Control. You can define allowed IP ranges for the entire organization or per user group.
Does HRNexus integrate with Slack?
Integrations
Yes, our official Slack app sends notifications for leave approvals, task assignments, performance reminders, and more. Install it from Settings → Integrations → Slack. Custom webhook triggers are also available on Pro and above.
Can I import employee data from another HR system?
Integrations
HRNexus supports CSV import and direct integrations with BambooHR, Workday, and SAP SuccessFactors. Use the import wizard under Settings → Data → Import Employees. The wizard validates your data before import and provides a detailed error report.
